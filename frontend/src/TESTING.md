# Звіт з інтеграційного тестування UI (ПР8)

## Підсумок тестування
- **Виявлено дефектів:** 1 (штучний дефект min-width за кроком 5).
- **Виправлено дефектів:** 1.
- **Пристрої та середовище:** Google Chrome / MS Edge (DevTools Device Mode).
- **Стан консолі:** Помилки та попередження відсутні.

---

## 1. Таблиця тестування контрольних ширин ( Responsive Mode )

| Ширина (px) | Орієнтир           | Кількість колонок | Виявлені дефекти / Примітки |
| :---        | :---               | :---:             | :---                        |
| **320**     | Малий смартфон     | 1                 | Дефектів не виявлено (після видалення min-width) |
| **375**     | iPhone SE          | 1                 | Без дефектів, адаптивний заголовок читабельний |
| **600**     | Межа tablet        | 2                 | Перебудова у 2 колонки пройшла успішно |
| **768**     | iPad (портрет)     | 2                 | Текст і відступи відображаються коректно |
| **1024**    | Межа desktop       | 3                 | Перебудова у 3 колонки успішна |
| **1280**    | Ноутбук            | 3                 | Шапка розміщена в один рядок |
| **1920**    | Десктопний монітор | 4 (або 3)         | Працює сітка згідно з налаштуваннями ПР7 |
